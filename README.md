# Employee Database System (SQL/MySQL)

A simple Employee Database System implemented using SQL. This project demonstrates basic CRUD operations using MySQL.

## 🔧 Features
- Create Database and Table
- Insert Employee Records
- View Employee Data
- Update Employee Salary
- Delete Employee Records

## 🧠 Concepts Used
- SQL (DDL & DML)
- CREATE, INSERT, SELECT, UPDATE, DELETE
- WHERE conditions

## 🚀 How to Run

1. Open MySQL
2. Run the script:

```sql
SOURCE employee_db.sql;
```

## 📌 Sample Queries

```sql
SELECT * FROM Employees;

UPDATE Employees
SET salary = 45000
WHERE name = 'Priya';
```
